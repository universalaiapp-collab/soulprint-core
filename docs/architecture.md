# Soulprint Architecture

Soulprint acts as a security firewall for AI agents.

Execution Flow:

1. Agent signs request
2. Soulprint verifies identity
3. Firewall checks action history
4. Escalation rules trigger if needed
5. Decision ledger records event
6. Action executes

Components:

Agent SDK
Firewall Engine
Escalation Engine
Decision Ledger
Metrics System
